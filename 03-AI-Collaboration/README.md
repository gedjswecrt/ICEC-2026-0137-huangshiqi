## 每篇的结构

**问题（贴日志/现象原文）→ 我的提问 → AI 给的方案 → 我的判断 → 验证 → 复盘**

「我的判断」是最要紧的一段——AI 的方案通常更周全，但周全不等于合适，取舍是我自己做的。
