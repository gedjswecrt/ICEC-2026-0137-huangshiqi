# 03-AI-Collaboration · AI 协作与排障记录

> 本目录收录考核期间与 AI 协作的关键过程：遇到的问题、我提的问题、AI 给的方案、**我做的判断**、以及验证结果。
>
> 记录原则：只记录真实发生过的事，每条都指向可核查的证据（日志行、报错原文、commit、截图）。

## 怎么读

- 想快速了解技术能力 → 看 **A 类**（技术排障），10 篇，每篇都有报错原文与修复验证
- 想看判断力 → 看 **B 类**（方案取舍），6 篇，重点在「AI 给了什么、我改了什么」
- 想看数据规范意识 → 看 **C 类**（数据真实性），4 篇

每篇结构统一：**问题（日志/现象原文）→ 我的提问 → AI 给的方案 → 我的判断 → 验证 → 复盘**。

## 关于 AI 协作的一点说明

这 20 条记录里，AI 承担的主要是**实现与排查**：写脚本、解析错误、给候选方案。
但以下判断是我自己做的，也是这些记录真正想留下的部分：

- 课题10 把五步拆分砍成单一动作（B02）
- 阶段二从视觉检测换成校园工具，判断依据是「10 天内哪个最不容易断」（B04）
- 数据与照片时间差选择如实声明而不是重录（C01）
- 日志里的报错全部保留（C04）
- 自动运行的两层兜底一个都不删（A05）

AI 的方案更周全，但**周全不等于合适**；把这些取舍写下来，比写「AI 帮我全做完了」更有意义。
