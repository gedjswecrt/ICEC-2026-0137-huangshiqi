# 迭代 3：v0.3 → v0.4（2026-11-16）

## 改动依据（用户反馈驱动，第 2 批第 1 位用户）

**依据一 · 用户反馈 U03（刘慧敏，2026-11-16 09:35）**，4 条改进意见全部落实（截图见 `screenshots/feedback_U03_刘慧敏_20261116.png`）：

> ① 倒计时文案有歧义："还剩 0 天"看不出是不是当天要交
> ② DDL 重点不突出：四条事项长得一样，紧急的没被强调
> ③ 课表缺少状态标识：分不清哪些课上完了、哪节正在上
> ④ 资讯和贴士混在一起：想要的通知和小知识分不开

**依据二 · 用户提出的需求**：学校官网（www.ssti.net.cn）的通知无法自动出现在早报里，希望能自动爬取——正好与 U03 的第 ④ 条（分栏）形成同一个改动方向。

## 改动内容

### 1. 新增「学校官网通知」板块（新模块 `src/campus_news.py`）

- 数据源：官网「通知公告」栏目列表页，单次请求即可拿到全部条目
- 解析方式：正则匹配（页面结构固定），**不引入 BeautifulSoup 等新依赖**——减少环境崩坏面，这是 v0.1→v0.2 教训（编码崩坏）的延续
- 降级策略与天气一致：超时 15 秒、失败不中断早报，板块显示"今日未获取到"，错误写入遥测日志

### 2. DDL 文案修复 + 紧急高亮（对应 U03 ①②）

| 剩余天数 | v0.3 显示 | v0.4 显示 |
|---|---|---|
| 0 天 | 还剩 0 天 | **今天截止！**（红色加粗） |
| 1 天 | 还剩 1 天 | **明天截止**（红色加粗） |
| 2~3 天 | 还剩 N 天 | 还剩 N 天（红色） |
| 4 天以上 | 还剩 N 天 | 不变 |

### 3. 课表状态标识（对应 U03 ③）

按早报生成时刻与课程起止时间比对，给今天的每节课加标签：`未开始`（蓝）/ `进行中`（橙）/ `已结束`（灰）。明天预告不加（还没到，无需状态）。

### 4. 通知与贴士分栏（对应 U03 ④）

原「📰 校园资讯 & 生活贴士」一张卡片拆成两张：`🏫 学校官网通知`（真实抓取，带原文链接）与 `💡 生活贴士`（tips.csv 轮换）。

### 5. 版本与留痕同步

- `VERSION` → v0.4（页脚可见）
- 本文件 + `VERSION_HISTORY.md` 更新；Git commit 待推送
