# 项目四：校园实用程序「每日校园早报」+ 7 天运行日志验证

**工具定位**：每天早上自动生成一份「校园早报」网页（今日天气 + 今日课程 + 临近 DDL + 备忘），生成后发到班级群供同学查看。

**选它的理由**：
- 自动化运行天然成立（Windows 任务计划程序每天 7:30 自动执行）→ 7 天 Telemetry 日志有保障
- 代码由 AI 辅助编写，本人负责设计、维护、迭代 → 符合"AI 辅助开发"的考核导向
- 同学查看成本极低（点开网页即可）→ 8 位真实用户反馈容易收集

## 评分对照（60分）

| 必交项 | 分值 | 我们的对应产出 |
|---|---|---|
| 连续 ≥7 天自动化运行日志（脱敏时间戳、调用频次、耗时、报错） | 25 | `process_logs/telemetry_*.jsonl`，每天自动追加 |
| 基于日志的 ≥3 次 Git 迭代 Diff | 20 | `iterations/iter1~3.md`（每次附 diff 与日志依据） |
| 完整源码 + 8 位真实用户反馈 | 15 | `src/` + 问卷截图与统计表 `docs/用户反馈.md` |

## 7 天日志窗口（倒排）

- **11/15（今天）**：v0.1 跑通，第一次日志 ✅ 起跑
- 11/16：配置任务计划程序，全自动；邀请同学使用

- 期间基于日志做 3 次迭代（每次 commit 留 diff）
- 11/22 ~ 23：收 8 人反馈、写 REPORT
- 11/24：截止

## 目录结构

```
02-20Days-Challenge/
├── README.md            # 本文件
├── docs/                # 实施方案、用户反馈
├── src/                 # 源码
│   ├── daily_brief.py   # 主程序
│   └── config.py        # 城市经纬度、路径等配置
├── data/                # 输入数据（课程表、DDL，可编辑）
├── output/              # 每天生成的早报 HTML
├── process_logs/        # ⭐ 每天 JSONL 运行日志（核心评分项）
└── iterations/          # 3 次迭代的 diff 记录
```

## 用户怎么用

1. 每天早上程序自动生成 `output/早报_YYYY-MM-DD.html`
2. 我把早报发到班级群（复制链接或直接发文件）
3. 同学阅读；第 8 天发问卷收集 8+ 人的使用反馈
