# 项目四：校园实用程序「每日校园早报」+ 7 天运行日志验证

**工具定位**：每天早上自动生成一份「校园早报」网页（天气 + 今日课程 + 临近 DDL + 学校官网通知 + 生活贴士），生成后发到班级群供同学查看。

**选它的理由**：
- 自动化运行天然成立（Windows 任务计划程序每天 7:30 自动执行）→ 7 天 Telemetry 日志有保障
- 代码由 AI 辅助编写，本人负责设计、维护、迭代 → 符合"AI 辅助开发"的考核导向
- 同学查看成本极低（点开网页即可）→ 8 位真实用户反馈容易收集

## 数据来源说明（哪些是自动的、哪些是手工维护的）

写真话比写得像全自动更可靠，也方便读者判断：

| 板块 | 来源 | 说明 |
|---|---|---|
| 今日天气 | **自动** | wttr.in 主源 + open-meteo 备源，失败时早报照常生成 |
| 学校官网通知 | **自动** | 抓取学校官网「通知公告」列表页，失败显示"今日未获取到" |
| 今日课程 / 明天预告 | 手工 | `data/schedule.csv`，本人按本学期课表录入 |
| 临近 DDL | 手工 | `data/ddl.csv`，本人手工登记的作业与考试截止时间（**非抓取教务系统**） |
| 生活贴士 | 本地内容池 | `data/tips.csv`，按日期轮换 |
| 今日一句话 | 自动生成 | 由当天课表状态与最近 DDL 实时拼接，无写死文案 |
| 降温提醒 | 自动生成 | 天气接口返回的今明两日气温：明天温度范围每天显示，降幅 ≥4°C 时才加一句添衣提醒（v0.7） |

### 关于 `output/示例_降温提醒_v0.7.html`

v0.7 的降温提醒是**条件触发**的——只有次日气温比今日低 4°C 以上才出现。如果上线后的某一天恰好没降温，早报上就不会有那一行，评审也就无法确认这个功能是否真的做了。

因此把 2026-11-19 晚间那次真实运行（当天恰好从 18°C 降到 13°C）的产物单独留档在此，作为**功能存在的实例证据**。文件内容与当天正式早报唯一差别就是页脚的 `v0.7` 和这一行提醒，其余数据完全相同。

## 用户怎么用

1. 每天早上 7:30 程序自动生成 `output/早报_YYYY-MM-DD.html`
2. 我把早报发到班级群（直接发文件或链接）
3. 同学阅读后反馈问题；每条反馈登记进 `data/feedback.csv`，截图存 `screenshots/`
4. 收到反馈后按"改版当天开发 + 验证、次日 7:30 上线"的节奏迭代
