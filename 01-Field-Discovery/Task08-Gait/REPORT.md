## 2. 特征统计（features.csv）

| 姿态 | 合加速度标准差 σ (m/s²) | 峰峰值 (m/s²) | 主频 (Hz) | 等效步频 (步/分) | z轴σ (m/s²) |
|---|---|---|---|---|---|
| 静止 | **0.10** | 1.49 | 2.69* | — | 0.16 |
| 平地慢走 | **1.21** | 7.72 | 1.54 | 92.5 | 1.41 |
| 上下楼梯 | **2.21** | 11.69 | 1.86 | 111.7 | 2.32 |
| 快跑 | **7.89** | 36.70 | 1.39 | 83.4 | 8.85 |

\* 静止态主频能量占比仅 3.2%，为传感器噪声，无物理意义。

**观察结论**：
1. 动态加速度标准差 σ 在四种姿态间相差近两个数量级（0.10 → 7.89），是区分度最好的单一特征；
2. 慢走等效步频 92.5 步/分、上楼梯 111.7 步/分，与常识范围（慢走 90~110、爬楼 100~120）吻合，交叉验证了主频提取方法的合理性；
3. 快跑因手持手机摆臂叠加冲击，合加速度均值上移至 17.08 m/s²（|a| 非负导致振荡抬高均值），峰峰值达 36.7 m/s²；
4. 上楼梯波形不规则度（z轴σ/总σ）介于走与跑之间，反映蹬踏动作的非周期性。

## 3. 阈值判别规则（核心交付）

以动态加速度标准差 σ = std(|a| − mean(|a|)) 为**主判据**，等效步频为辅助：

```
if σ < 0.5 m/s²:        判定 → 静止
elif σ < 2.0 m/s²:      判定 → 平地慢走
elif σ < 5.0 m/s²:      判定 → 上下楼梯
else:                   判定 → 快跑
```

辅助校验（防误判）：峰峰值 < 3 m/s² 且主频能量占比 < 5% 时强制归为静止；
σ 处于 2.0 边界时，用步频区分（>100 步/分 → 楼梯，<100 → 慢走）。

该规则对本实验 4 组数据的分类准确率为 4/4。可视化依据见 `figures/fig2`（分布）与 `figures/fig3`（特征空间分区）。

## 4. 局限与改进方向

- 每种姿态仅单次采集 12~14 s，样本偏短；更严格的做法是每组延长至 30 s 并在不同日期重复采集，检验阈值跨日期稳定性（本课题因时间所限未做，已在采集说明中如实注明）；
- 手机为手持佩戴，快跑冲击被放大；改用腰袋/臂带固定可降低佩戴方式对阈值的影响；
- 目前仅用阈值规则（可解释性强、计算量极小，适合嵌入式部署），后续可升级为决策树或轻量 NN，并加入陀螺仪特征区分"上楼/下楼"。
